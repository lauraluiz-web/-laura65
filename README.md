# 🏫 Dashboard Escolar - Colégio Inovação

Este projeto é um **Dashboard Escolar** desenvolvido utilizando apenas **HTML5** e **CSS3**, aplicando conceitos avançados de estruturação com **CSS Grid** e **Flexbox**, além de práticas de design moderno, responsividade e organização.

---

## 💻 Recursos Utilizados
- **HTML5 Semântico:** `<header>`, `<aside>`, `<main>`, `<section>`, `<table>`, `<footer>`.
- **CSS3 Avançado:** CSS Grid Layout, Flexbox, Variáveis CSS (`:root`), Badges personalizadas e Sombras suaves.
- **Responsividade:** Adaptação completa para dispositivos móveis e tablets com `@media queries`.
